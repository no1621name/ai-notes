# AI Notes

Это приложение для заметок, созданное на Vue 3.

## Ключевые возможности
- ✨ **Редактирование с ИИ**: Промпты, модификация и генерация текста с помощью ИИ моделей прямо в редакторе.
- 💾 **Локальное хранение**: Все заметки и настройки безопасно хранятся в вашем браузере (IndexedDB).
- 🏷️ **Организация**: Держите мысли структурированными с помощью тегов.
- ⏰ **Напоминания**: Устанавливайте напоминания для заметок.
- 🌐 **Интернационализация**: Приложение поддерживает несколько языков.

## Технологический стек
- **Фреймворк и сборка**: Vue 3, Vite
- **Стилизация**: Tailwind CSS, daisyUI
- **Управление состоянием**: Pinia
- **Получение данных**: TanStack Query
- **Редактор**: Tiptap
- **Формы и валидация**: Regle, Artype
- **Тестирование**: Vitest
- **Менеджер пакетов**: pnpm
- **I18n**: Vue I18n
- **Архитектура**: [FSD](https://fsd.how/ru/docs/get-started/overview/)
- **Логика уведомлений**: Supabase Edge Functions
- **CI/CD**: GitHub Actions + Netlify

## Поддерживаемые провайдеры и языки

На данный момент в качестве провайдера для ИИ моделей поддерживается только [Groq](https://groq.com/). Если вам нужна поддержка других провайдеров, создайте issue.

Также сейчас поддерживаются только английский и русский языки. Если вам нужна поддержка других языков, создайте issue.
